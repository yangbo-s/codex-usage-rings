# v0.2.0 — macOS 预览版

Codex Usage Rings 首个 GitHub 预览发布。一个真实账户对应一个菜单栏绿色圆环，中心显示剩余百分比。

## 功能

- 本机 Codex 登录自动连接；额外账户使用独立配置目录。
- 单额度窗口使用粗单环；长周期与 5 小时额度同时存在时使用同心环。
- 每个可用 banked reset 显示为一条绿色竖线，只读不兑换。
- 原生用量面板、账户昵称与管理、登录时启动开关。
- 5 分钟后台刷新、低电量模式 15 分钟、睡眠暂停、读取后关闭查询进程。
- 简约绿色圆环应用图标；没有演示模式。

## 下载与安装

下载 `Codex-Usage-Rings-v0.2.0-macos-arm64.dmg`，双击打开，把 `Codex Usage Rings.app` 拖到 `Applications`。复制完成后推出磁盘映像，再从“应用程序”启动。

此 DMG 包含与原 v0.2.0 ZIP 相同的应用程序；版本标签保持不变。ZIP 仍保留为备选下载。

- **芯片**：Apple Silicon / arm64。
- **最低系统**：macOS 13。
- **运行依赖**：已安装并以 ChatGPT 账户登录的 Codex CLI 或 Codex / ChatGPT 桌面应用。安装包不包含 Codex CLI。
- **校验**：同时下载 `SHA256SUMS.txt`，在同一目录执行 `shasum -a 256 --ignore-missing -c SHA256SUMS.txt`。
- **签名**：ad-hoc，未做 Developer ID 签名与 Apple 公证。初次打开可能需要按 [Apple 的说明](https://support.apple.com/zh-cn/102445)在“隐私与安全性”中允许此应用。

## 已知限制

当前为预览版，仅提供 arm64 安装包，不含 Intel 或 Universal 构建，没有自动更新。多账户登录、系统登录启动和辅助功能的兼容性仍需完善。
