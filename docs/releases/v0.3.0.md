# v0.3.0 — 更紧凑的圆环与自动收起

- 顶栏圆环从 24pt 缩至 20pt，详情圆环从 44pt 缩至 36pt；绿色环线和 banked reset 竖线更细。
- 环内只显示数字，省略 `%`；详情、悬停提示和辅助功能仍保留百分比单位。
- 新增“自动收起面板”：鼠标移出后默认 3 秒，可在“账户与设置”输入 1–300 秒或关闭；移回面板、编辑文字时暂停，设置自动保存。
- 展开/收起启用原生系统过渡，遵循“减少动态效果”；切换账户直接调整弹窗位置。
- 自动收起只用一枚可取消的一次性计时器，无鼠标轮询或持续动画；后台 5/15 分钟刷新策略保持原样。

## 安装

下载 `Codex-Usage-Rings-v0.3.0-macos-arm64.dmg`，退出正在运行的旧版，打开 DMG，将应用拖入 Applications 替换旧版，再重新打开。既有账户保留，旧配置自动补上新设置。

适用于 Apple Silicon、macOS 13+。需要已安装并以 ChatGPT 账户登录的 Codex CLI 或 Codex / ChatGPT 桌面应用。下载 `SHA256SUMS.txt` 后在同一目录运行 `shasum -a 256 -c SHA256SUMS.txt`。

## 验证与限制

25 项自动测试通过，覆盖收起计时取消、过期回调、编辑暂停、设置迁移与持久化，以及既有数据/进程/刷新路径；浅深色原生离屏图已检查。release 构建、签名、DMG 完整性与只读挂载检查见仓库验收记录。

原生 UI 自动化连接超时，未将离屏图当作真实鼠标交互或动画观感验证；长期电池耗电、多账户真实 OAuth、重启登录和跨 macOS 版本测试仍未完成。

当前为预览版，采用 ad-hoc 签名，尚未做 Developer ID 签名与 Apple 公证。初次打开可能需要按 [Apple 的说明](https://support.apple.com/zh-cn/102445)在“隐私与安全性”中允许。
