# v0.4.0 — 余量分色与更紧凑的圆环

- 顶栏圆环从 20pt 缩至 18pt，详情仍为 36pt。
- 按显示的剩余整数分色：75–100 绿色、50–74 蓝色、25–49 黄色、0–24 红色。内外环分别按自身额度取色，详情条保持一致。
- 浅色外观使用较深的绿色与金黄色，深色外观使用较亮颜色；0% 显示淡红空轨道，未知和过期仍为灰色。
- Reset 竖线与当前外环同宽，继续独立保持绿色，数量仍表示可用 reset。
- 中心使用实际字形边界适配，`100` 尽量放大但不碰环线。已比较 `Full`，应用保留数字表达，未添加显示切换或演示模式。

刷新时间本轮仅讨论，现有 5/15 分钟策略、按需更新和低耗电行为未变；未增加可调刷新设置。

## 安装

下载 `Codex-Usage-Rings-v0.4.0-macos-arm64.dmg`，退出旧版，将映像中的应用拖入 Applications 替换后重新打开。账户与收起设置保留。

适用于 Apple Silicon、macOS 13+；依赖本机已登录的 Codex。下载同目录的 `SHA256SUMS.txt` 后，执行 `shasum -a 256 -c SHA256SUMS.txt` 校验。
