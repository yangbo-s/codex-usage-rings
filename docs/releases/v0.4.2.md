# v0.4.2 — 紧凑顶栏与 Reset 到期时间

顶栏入口按内容收紧宽度，移除额外留白。1 次 reset 显示一根绿色线，2 次显示两根，3 次及以上显示一根实线加竖向三点，最多占两列；线宽与点径均跟随外环。

点击圆环，面板显示准确次数和 Reset 到期时间，使用本地时间，从早到晚排列，相同时间合并次数。接口明确没有期限时显示“不过期”，缺失或明细不完整时显示“到期时间未知”。

账户 `pro` 显示为 **Pro 200**，其他档位独立命名。保留 v0.4.1 的直接“退出”按钮和 ⌘Q。

下载 `Codex-Usage-Rings-v0.4.2-macos-arm64.dmg`，退出旧版后拖入 Applications 替换。账户与设置保留。适用于 Apple Silicon、macOS 13+；仍为未公证的 ad-hoc 签名预览版。
