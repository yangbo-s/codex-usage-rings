# v0.5.0 — Credit 余额与菜单栏自定义

- 详情面板的每周额度下新增 Credit 余额；最多显示两位小数，未知与无限分别表达，菜单栏不显示余额数值。
- 额度耗尽且有可用 credits 时显示红色 `C`；没有 credits 时保留 `0`，额度恢复后显示正常数字。数据过期仍沿用灰色提示。
- 多账户可选择菜单栏显示数量，并通过上下箭头调整从左到右的顺序；仅一个账户时自动显示它。
- 数量与顺序自动保存；未显示在菜单栏的账户仍可在面板查看并继续刷新。旧配置默认继续显示全部账户。

复用原有用量请求，没有新增轮询、模型调用或依赖。`C` 表示额度耗尽且尚有 credits，不是扣款交易状态。

适用于 Apple Silicon、macOS 13+。沿用预览版发布方式，采用 ad-hoc 签名，尚未经过 Apple 公证；校验文件为同一 Release 的 `SHA256SUMS.txt`。

验证覆盖自动测试、浅深色原生离屏渲染、真实账户余额读取和安装包签名。真实菜单栏左右位置与点击操作尚未取得现场验证。
